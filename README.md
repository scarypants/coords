# 좌표 어디더라

> 좌표 아는 사람?

친구들끼리 마인크래프트(자바 에디션) 좌표를 모아 두는 웹앱입니다. 마을, 지옥문, 집, 농장 같은 위치를 등록하면 방에 있는 모두가 바로 보고, tp 명령어를 한 번에 복사할 수 있습니다. 폰에서 좌표를 보며 플레이하는 일이 많아서 폰과 PC 둘 다 편하게 만들었습니다.

## 할 수 있는 것

- **좌표 등록**: 종류, 이름, 차원(오버월드, 네더, 엔드), X Y Z, 메모. "나만 보기"로 숨길 수도 있습니다.
- **목록**: 종류, 등록한 사람, 검색으로 찾고, 누르면 책 페이지 모양으로 자세히 봅니다. 네더와 오버월드 대응 좌표도 같이 나옵니다.
- **tp 복사**: 차원에 맞는 명령어(`/tp`, `/execute in ... run tp`)를 복사합니다.
- **나침반**: 친구가 등록한 좌표를 주워 내 인벤토리에 넣습니다.
- **인벤토리**: 내 좌표와 주운 좌표가 마크 인벤토리처럼 칸에 들어갑니다. 칸을 옮기고 핫바에 대표 좌표를 둘 수 있고, 배치는 폰과 PC에서 같게 유지됩니다. 스킨을 고르거나 내 스킨 PNG를 올리고, 방장이 준 갑옷을 입습니다(방어력 0).
- **서버 주소**: 상단에서 바로 보고 복사합니다. 바뀌면 접속 중인 모두에게 알림이 뜹니다.
- **로그인**: 회원가입은 없고, 방장이 친구마다 아이디와 비밀번호를 만들어 줍니다. 한 번 로그인한 기기는 다음부터 자동으로 들어가고, 비밀번호는 각자 바꿀 수 있습니다.

## 만든 방식

빌드 도구 없는 정적 웹페이지(HTML, CSS, JavaScript 모듈)를 GitHub Pages에 올리고, 데이터와 실시간 갱신, 익명 로그인은 [Supabase](https://supabase.com)를 씁니다. 별도 서버는 없습니다.

글꼴은 [Galmuri](https://github.com/quiple/galmuri)(SIL Open Font License 1.1, `assets/fonts/OFL.md`)를 씁니다. 마인크래프트와 관련된 그림은 모두 직접 그린 것이며, Mojang의 공식 리소스는 포함하지 않습니다.
